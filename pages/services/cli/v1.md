# CLI and commands

The [[mod:cli]] runs as `node <skill-dir>/bin/redocs.mjs <command>`. Every command prints a human summary, or a JSON receipt with `--json`. Exit codes: `0` success, `1` content or check failure, `2` usage error.

## Commands

| Command | Does | Component |
|---|---|---|
| `init <dir> --name <id> [--title] [--language]` | Scaffold a book from the starter; refuses non-empty folders | [[mod:authoring]] |
| `add-page <book> <page-id> --title --kind [--chapter] [--variants] [--html] [--standalone]` | Create `page.json` + source, add it to a chapter | [[mod:authoring]] |
| `add-entity <book> <id> --type --name [--since] [--until] [--replaced-by] [--depends-on]` | Add an entity to `entities/<type>.json` | [[mod:authoring]] |
| `add-variant <book> <page-id> <milestone>` | Create a variant from the body it currently inherits | [[mod:authoring]] |
| `promote <book> <milestone>` | Move the `current` milestone, print what to review | [[mod:promote]] |
| `embed <book> <plugin> <id> --spec <file> [--type]` / `embed <book> --refresh-stale` | Render an artifact and write its receipt | [[mod:embed]] |
| `check <book> [--strict]` | Run RD000–RD012; writes nothing | [[mod:check]] |
| `build <book> [--out]` | Write `dist/` | [[mod:build]] |
| `pack <book> [--out]` | Zip `dist/` | [[mod:pack]] |
| `finalize <book> [--strict]` | check → build → browser check | [[mod:finalize]] |

## Environment variables

| Variable | Effect |
|---|---|
| `REDOCS_CHROME` | Chrome/Chromium executable |
| `REDOCS_CHROME_NO_SANDBOX=1` | Disable Chrome's own sandbox inside an already-sandboxed agent shell; does not relax `file://` rules |
| `REDOCS_ARCHIFY` | archify skill folder |

If the browser check cannot run, `finalize` fails; `--skip-browser` is accepted only together with `--allow-skip-browser`.
