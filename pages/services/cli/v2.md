# CLI and commands

The [[mod:cli]] runs as `node <skill-dir>/bin/redocs.mjs <command>`. Every command prints a human summary, or a JSON receipt with `--json`. Exit codes: `0` success, `1` content or check failure, `2` usage error.

> The v2 variant is a **proposal**, not implemented. See [Proposal: phase 2](page:proposals/phase-2).

## Commands

All v1 commands stay; added:

| Command (proposed) | Does | Component |
|---|---|---|
| `present <book> <chapter> [--milestone]` | Present one chapter as slides, one slide per `##` | [[mod:presentation]] |
| `export-pdf <book> <chapter> [--milestone]` | Print one chapter to PDF with headless Chrome | [[mod:pdf-export]] |

Every page `build` writes shows its interface strings in the book's `language` ([[mod:ui-i18n]]).
