# Runtime environment (v1): file://

A v1 book has a single environment: **the reader's browser opening files from disk**. No server, no network.

## Behaviour verified by the spike (Chrome 155, 2026-10-18)

| Behaviour | Result | Design consequence |
|---|---|---|
| iframe with a relative `src` to a local file | works | artifacts embed as iframes |
| Parent reads `iframe.contentDocument` | **fails** (opaque origin) | the parent cannot measure height |
| `postMessage(…, '*')` from iframe to parent | works | the iframe reports its own height |
| Data through `<script src>` | works | the search index is `search-index.js` |
| `localStorage` | works | theme preference, with a `prefers-color-scheme` fallback |
| `fetch()` of a local file | **blocked** (CORS) | `fetch()` is forbidden in output |
| Relative links across folders, `../` | works | every href is relative |
| `<meta http-equiv="refresh">` | works | `dist/index.html` redirects to the current milestone |

The same output also works when served over HTTPS, which is how this book is published on GitHub Pages.
