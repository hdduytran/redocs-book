    CLI and commands

    The redocs CLI runs as node <skill-dir>/bin/redocs.mjs <command>. Every command prints a human summary, or a JSON receipt with --json. Exit codes: 0 success, 1 content or check failure, 2 usage error.

    Commands

    Command Does Component
    init <dir> --name <id> [--title] [--language] Scaffold a book from the starter; refuses non-empty folders Authoring commands
    add-page <book> <page-id> --title --kind [--chapter] [--variants] [--html] [--standalone] Create page.json + source, add it to a chapter Authoring commands
    add-entity <book> <id> --type --name [--since] [--until] [--replaced-by] [--depends-on] Add an entity to entities/<type>.json Authoring commands
    add-variant <book> <page-id> <milestone> Create a variant from the body it currently inherits Authoring commands
    promote <book> <milestone> Move the current milestone, print what to review Promote
    embed <book> <plugin> <id> --spec <file> [--type] / embed <book> --refresh-stale Render an artifact and write its receipt Embed + plugin registry
    check <book> [--strict] Run RD000–RD012; writes nothing Check gate
    build <book> [--out] Write dist/ Build
    pack <book> [--out] Zip dist/ Pack
    finalize <book> [--strict] check → build → browser check Finalize

    Environment variables

    Variable Effect
    REDOCS_CHROME Chrome/Chromium executable
    REDOCS_CHROME_NO_SANDBOX=1 Disable Chrome's own sandbox inside an already-sandboxed agent shell; does not relax file:// rules
    REDOCS_ARCHIFY archify skill folder

    If the browser check cannot run, finalize fails; --skip-browser is accepted only together with --allow-skip-browser.
