    Components

    ReDocs is one skill package (skill/redocs/) holding the agent contract, the CLI, the engine and the plugins. The Catalog lists every component; this page shows the boundaries.

    Layer Components Main files
    Agent contract SKILL.md + references SKILL.md, references/*.md, templates/book-starter/AGENTS.md
    Command interface redocs CLI bin/redocs.mjs
    Authoring Authoring commands, Promote lib/command-init-book.mjs, lib/command-add-page-entity-variant.mjs, lib/command-promote-milestone.mjs
    Model Loader + schemas lib/load-book-from-directory.mjs, lib/validate-book-schemas.mjs, schemas/*.schema.json
    Rendering Renderer lib/render-book-pages.mjs, lib/render-markdown-with-redocs-extensions.mjs, lib/render-html-fragment-with-redocs-extensions.mjs, lib/render-redocs-references.mjs
    Checking Check gate lib/check-book-rules.mjs, lib/command-check-book.mjs
    Publishing Build, Pack lib/command-build-book-site.mjs, lib/build-generated-pages.mjs, lib/render-page-shell-layout.mjs, lib/command-pack-book-zip.mjs
    Final gate Finalize, Chrome CDP checker lib/command-finalize-book.mjs, lib/chrome-cdp-file-protocol-check.mjs
    Plugins Embed + plugin registry, archify plugin, html plugin lib/command-embed-artifact.mjs, lib/load-plugin-registry.mjs, plugins/*/
    Reader UI (theme) assets/theme/redocs.css, assets/theme/redocs.js

    Key boundaries

    • The loader never throws for content: broken JSON, schema errors and duplicate ids all become diagnostics. Only a missing book.json stops it.
    • Renderers record, they do not judge: links, entities, embeds and assets are recorded in the render context; Check gate decides what is an error once every page at every milestone is rendered (anchors need that).
    • Build does not check itself: it renders and writes; finalize combines check, build and the browser.
